## 🎮 프로젝트 개요

**Shooting_Game_JS**는 JavaScript를 사용하여 제작된 간단한 슈팅 게임입니다.  
플레이어는 캐릭터를 조작하며 적을 제거하고 점수를 획득합니다.  
**스릴 넘치는 전투**와 **간단한 조작법**으로 재미있게 즐길 수 있습니다.

🎮 [**게임하러 가기!**](https://66f74a596d45dc1814fff657--lovely-daifuku-6afc1d.netlify.app/)

---

## 🎯 주요 특징

- **캐릭터 이동**: **← → 키**로 이동  
- **총알 발사**: **스페이스바**를 사용해 적을 공격  
- **점수 획득**: 적을 제거할 때마다 점수 증가  
- **위험 요소**: 적 캐릭터와 부딪히면 **Game Over**

## 🕹️ 게임 방법

1. **캐릭터 이동**  
   - **← 키**: 왼쪽으로 이동  
   - **→ 키**: 오른쪽으로 이동  

2. **공격**  
   - **스페이스바**: 총알 발사  

3. **점수 획득**  
   - 적 캐릭터를 공격해 제거하면 점수가 상승합니다.  

4. **Game Over**  
   - 적 캐릭터와 부딪히면 게임이 종료됩니다.

---

## 🌟 게임의 매력

- **간단한 조작법**: 누구나 쉽게 익힐 수 있는 직관적인 컨트롤  
- **중독성 있는 게임성**: 높은 점수를 도전하며 몰입 가능  
- **무작위 생성**: 매번 새로운 플레이 경험 제공
